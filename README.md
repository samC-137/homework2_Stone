# Primitive DB

Консольная программа для работы с примитивной базой данных в JSON-файлах.

## Запуск

```bash
uv sync
uv run database
```

Команда `help` показывает доступные команды. Строковые значения вводятся в кавычках.

Удаление таблицы и записей требует подтверждения. Ошибки команд выводятся в консоль.
